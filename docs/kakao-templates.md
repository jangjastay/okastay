# 카카오 알림톡 템플릿 (심사 등록용)

솔라피 → 카카오 알림톡 → 템플릿 등록에 아래 4개를 **그대로** 넣으세요.
`#{…}` 부분은 변수라서 예약마다 자동으로 바뀝니다. 글자 하나라도 바꾸면 시트 코드와 안 맞을 수 있으니, 고치고 싶으면 먼저 말해주세요.

- 카테고리: **예약 > 예약 안내**(또는 예약완료/예약취소에 맞춰 선택)
- 메시지 유형: 기본형 · 강조 유형: 선택 안 함
- 버튼: 웹링크 1개 `홈페이지` → https://okastay.kr (선택)

심사 통과 후 나오는 **템플릿 ID**를 예약 시트 `설정` 탭의 `템플릿ID_신청 / 입금대기 / 확정 / 취소` 칸에 넣으면 됩니다.

---

## 1. 신청 (예약 신청 접수)

```
[오카맨션] 예약 신청 접수 안내

#{이름}님, 예약 신청이 접수되었습니다.

- 상품: #{상품}
- 일정: #{날짜}

빈 객실을 확인한 뒤 입금 안내를 보내드립니다.
입금이 확인되어야 예약이 확정됩니다.

문의: #{문의전화}
```

## 2. 입금대기 (입금 안내)

```
[오카맨션] 입금 안내

#{이름}님, 신청하신 일정 예약이 가능합니다.

- 상품: #{상품}
- 일정: #{날짜}
- 입금 금액: #{금액}
- 입금 계좌: #{입금계좌}
- 입금 기한: #{입금기한}까지

입금자명은 예약자 성함으로 부탁드립니다.
기한 내 입금이 확인되지 않으면 신청이 취소됩니다.

문의: #{문의전화}
```

## 3. 확정 (예약 확정)

```
[오카맨션] 예약 확정 안내

#{이름}님, 입금이 확인되어 예약이 확정되었습니다.

- 상품: #{상품}
- 일정: #{날짜}
- 입실: #{입실}
- 주소: #{주소}

환불 규정은 홈페이지 이용안내에서 확인하실 수 있습니다.

문의: #{문의전화}
```

## 4. 취소 (예약 취소)

```
[오카맨션] 예약 취소 안내

#{이름}님, 아래 예약이 취소 처리되었습니다.

- 상품: #{상품}
- 일정: #{날짜}

이미 입금하신 경우 환불 규정에 따라 처리해 드립니다.

문의: #{문의전화}
```
